## 📚 About

This repository is a collection of React exercises built while learning core concepts (components, props, state, and project structure).
Each exercise lives in its own folder and can be viewed through a simple switcher inside the app.

## 🛠️ Built With

- ⚛️ React
- ⚡ Vite
- 🎨 CSS
- 📦 JavaScript (ES6+)

## 🚀 Getting Started

\`\`\`bash
npm install
npm run dev
